Weiterempfehlung als Recruiting-Kanal: Wie Sie ein Empfehlungsprogramm im Handwerk aufbauen

6. September 2026

Im Handwerk ist Mundpropaganda oft der wirksamste Recruiting-Kanal, wird aber selten systematisch genutzt. Ein einfaches Empfehlungsprogramm macht aus zufälliger Weiterempfehlung einen verlässlichen, wiederholbaren Kanal.

Warum Empfehlungen so gut funktionieren

Wer von einem Kollegen oder ehemaligen Lehrmeister von einer offenen Stelle erfährt, hat bereits Vertrauen in die Quelle. Diese Vorabqualifikation fehlt bei jeder anderen Recruiting-Methode komplett.

Schritt 1: aktiv danach fragen

Die meisten Mitarbeitenden würden jemanden empfehlen, wenn sie gefragt würden, aber die wenigsten Betriebe fragen aktiv. Ein kurzer, regelmässiger Hinweis, zum Beispiel bei einer Teambesprechung oder in einer WhatsApp-Gruppe, reicht oft schon aus.

Schritt 2: den Weg so einfach wie möglich machen

Wenn eine Empfehlung bedeutet, dass jemand ein langes Formular ausfüllen muss, wird sie seltener genutzt. Ein einfacher Weg, etwa eine Nachricht direkt an Sie oder eine kurze Kontaktaufnahme per WhatsApp, senkt die Hürde deutlich.

Schritt 3: eine Anerkennung anbieten, wenn sinnvoll

Eine kleine Anerkennung, zum Beispiel eine Prämie nach bestandener Probezeit der empfohlenen Person, kann zusätzliche Motivation schaffen. Wichtig ist, dass sie fair und für alle im Team gleich geregelt ist.

Schritt 4: Danke sagen, unabhängig vom Ergebnis

Nicht jede Empfehlung führt zu einer Einstellung. Wer sich trotzdem bedankt, sorgt dafür, dass auch beim nächsten Mal wieder eine Empfehlung kommt.
